# Simple E-Commerce Store

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## Features
1. Product listing
2. Product details
3. Shopping cart
4. User registration
5. User login
6. Order processing
7. Order history
8. Database for users, products and orders

## How to run

1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal in VS Code.
4. Run:

npm install

5. Then run:

npm start

6. Open Chrome and visit:

http://localhost:3000

The SQLite database file `store.db` is created automatically when the server starts.
